# Cooledtured 'n Clean

A laundry pickup and wash-and-fold service website concept built for Cooledtured.

**Bacteria culture is out, cooledtured is in.**

## Overview

Cooledtured 'n Clean is a web-based concept for the laundry service. The website is designed to give customers an easy way to learn about the service, estimate laundry costs, and explore pickup and delivery options.

## Features

- **Responsive Navigation:** Simple navigation designed for desktop and mobile devices.
- **Interactive Homepage:** Branded landing page with animated background elements.
- **Laundry Cost Calculator:** Estimates service costs based on laundry weight at $2 per pound.
- **Pricing Information:** Clearly communicates service pricing and available options.
- **Branded Design:** Incorporates Cooledtured's visual identity, colors, and logo.

## Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript
- Lucide React

## Running Locally

To run the project on your local machine:

1. Clone the repository:

   ```bash
   git clone https://github.com/tnthai0905/cooledtured-laundry.git
   ```

2. Navigate to the project directory:

   ```bash
   cd cooledtured-laundry
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL provided by Vite in your browser.

## Deployment

The website is hosted using GitHub Pages. GitHub Actions automatically builds and deploys updates whenever changes are pushed to the `main` branch.
